# SmokeFix AI roadmap

### Phase 0 (week 1-2)
- Landing page + QR onboarding
- Manual smoke video + engine photo analysis
- Validate driver willingness to upload photos/videos
- Collect first 20 real cases

### Phase 1 (week 3-6)
- Flutter app for Android/iOS
- Gemini-based smoke detection + common issue suggestions
- Photo annotation guidance (air filter, hoses, obvious leaks)
- Before/after smoke score with donation prompt

### Phase 2 (week 7-12)
- Expand vehicle coverage (high-volume pickup/truck models)
- Partnerships: petrol stations, songthaew co-ops, schools
- Fleet dashboards + anonymized impact metrics

### Operating principles
- Safety: DIY only for simple maintenance
- Evidence: before/after improvement required for donation prompt
- Accessibility: primarily image/video input (minimal typing)
