# Datasets

We don't have real-world photos yet, so we will seed the first models/workflows using public datasets. **Before using any dataset for production**, we will verify its license and attribution requirements.

## Candidates
- Roboflow Universe: `vehicle-smoke-pollution` (smoke detection dataset)
- Roboflow Universe: `car-with-smoke`
- GitHub: `DB-Net-Vehiclesmoke` / PoVSSeg references (vehicle smoke segmentation)
- Stock video/photo sources for synthetic smoke clips (Pexels, Pixabay, etc.)

## Goal
Build an initial smoke-type classifier and UI demo, then replace training data with real user-sourced cases once we start the field pilot.
